# SimpleWeatherClient v1.0.3

This patch corrects weather and geocoding results and adds an NUnit regression suite for .NET Framework 4.7.2 and .NET 10. Public constructor and method signatures remain compatible.

## Fixes

- Weather and geocoding requests format coordinates consistently across regional settings and correctly escape query values.
- City searches parse the returned JSON objects, and geocoding accepts both integral and fractional coordinates.
- HTTP responses are disposed after reading. Calls on a disposed weather controller report `ObjectDisposedException` consistently.
- Numeric string readings parse independently of the current culture.
- One Call current weather includes wind and sun times; free current weather preserves station metadata.
- Free forecasts populate temperature, wind and cloud fields correctly. Hourly wind direction uses the returned bearing, and precipitation probability is reported as a percentage (for example, `0.65` becomes `65`).
- Daily forecast summaries select the weather nearest noon and respect fractional-hour time zone offsets when grouping readings.

## Tests and live option

`SimpleWeather.Tests` is included in the existing Visual Studio solution and uses the NUnit adapter. Validation passed **117 offline tests and four live tests on each target framework**. CI and release builds run the offline suite only.

The separate Live fixture checks actual current weather, forecasts, reverse geocoding and city search through your OpenWeather account. Live tests are disabled by default. Opt in with `live.runsettings` or the private JSON enable flag; API requests count against the account's applicable quota. Account credentials and local settings are excluded from Git and build/publish output. A placeholder settings example is included.

See the [testing guide](https://github.com/oznetmaster/SimpleWeatherClient/blob/v1.0.3/docs/testing.md) for Visual Studio, command-line instructions and private configuration.

## Dependencies and upgrading

This release updates log4net to 3.4.0 and the .NET Framework Microsoft.Bcl.AsyncInterfaces and Microsoft.Bcl.Memory dependencies to 10.0.12. The library continues to target net472 and net10.0.

Update the `SimpleWeatherClient` NuGet package to **1.0.3**. No source migration is required, but applications will now receive corrected measurements and percentages where earlier releases returned incomplete or incorrect values. The test project itself is not published to NuGet.
