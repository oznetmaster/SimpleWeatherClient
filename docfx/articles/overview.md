# SimpleWeather API Overview

SimpleWeather exposes a strongly typed wrapper over the OpenWeather APIs. The library provides:

- `WeatherController` for orchestrating current conditions and forecasts
- Models that mirror the One Call response (`Current`, `Hourly`, `Daily`, etc.)
- Utility helpers for geolocation and payload parsing
